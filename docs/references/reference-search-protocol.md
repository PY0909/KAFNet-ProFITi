# 文献检索与核验协议

## 数量要求

- 总数：精简为 31 篇核心核验文献，并按开题报告正文首次出现顺序编号。
- 英文：优先保留顶会、顶刊和核心方法原文。
- 中文：只保留与工业预测性维护、剩余寿命、异步监测、多变量退化、智能诊断和故障检测强相关的中文权威期刊、985 高校主办期刊或高质量学术期刊文献。
- 年份：优先 2022-2026，除非是不可替代的经典方法，否则不纳入。
- 每篇必须有真实链接。

## 主题分组

1. 工业预测性维护与设备状态预测。
2. 异步、不规则、缺失多元时间序列建模。
3. 概率预测、不确定性量化与校准。
4. RUL、健康状态预测与风险评估。
5. KAFNet、KST ProbFlow、ProFITi、GraFITi、PatchTST、TimesNet、iTransformer、RAINDROP、NCDSSM、TACTiS、TACTiS-2、Conformal Prediction、TranAD、DCdetector 等相关模型。

## 核验规则

每篇文献必须记录：

```text
sequence,language,year,title,authors,venue,source_type,source_level,topic,url,used_in,in_text_citation,citation_gbt_7714_2025,verified_date
```

英文文献优先使用 DOI、出版社页、会议页或 arXiv。中文文献优先使用 CNKI、万方、维普、期刊官网或 DOI。无法确认来源真实性的条目不进入最终开题报告。

## 本轮核验补充

- 引用表按开题报告正文首次出现顺序重新编号，正文引用使用“作者等[序号]”或“两位作者[序号]”形式；不按中文/英文文献类型单独排序。
- `citation_gbt_7714_2025` 列按顺序编码制 GB/T 7714 著录习惯整理，保留 `[J/OL]`、`[C/OL]`、`[EB/OL]` 和访问日期。
- 985 高校硕博学位论文仅在存在稳定可核验论文详情页或原文链接时纳入。无法稳定打开的 CNKI/万方动态检索结果不写入最终引用表，避免把不可复核条目混入开题报告。
- arXiv 条目只用于模型原文、最新方法或会议论文公开版本；若已有稳定会议/出版社页，优先记录会议/出版社页。

## 使用位置

- `1.2 国内外研究现状`：用于综述。
- `1.3 述评`：用于归纳不足。
- `5.1 研究方法`：用于说明实验与模型依据。
- `主要参考文献`：只列入已核验条目。
