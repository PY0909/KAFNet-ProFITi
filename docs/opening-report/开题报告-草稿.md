# 面向工业设备异步多传感器的概率状态预测与风险评估方法研究

## 1. 选题背景、国内外研究现状及述评

### 1.1 选题背景

工业设备在运行过程中会持续产生压力、温度、电流、流量、振动等多源传感器数据。这些数据能够反映设备运行状态、退化趋势和潜在故障风险，是预测性维护和智能运维的重要基础。与理想规则采样时间序列不同，真实工业场景中的传感器经常受到采样频率不一致、通信延迟、传感器离线、工况切换和异常中断等因素影响，形成异步、缺失、多变量耦合的观测序列。若直接使用固定插值或点预测模型，容易引入伪观测并忽略未来状态的不确定性。

本研究面向工业设备异步多传感器数据，拟构建能够同时进行未来状态概率预测和风险评估的方法。研究重点不是单纯判断某一时刻是否故障，而是从历史异步观测中学习规整表示，预测未来多传感器状态的联合分布，并进一步将预测分布转化为可解释的风险分数和预警指标。

### 1.3 研究述评

现有研究仍存在三方面不足：第一，许多方法依赖规则采样或固定插值，难以充分适应工业传感器异步缺失观测；第二，点预测模型难以表达未来状态的不确定性和多传感器联合相关性；第三，工业运维需要可解释且校准的风险输出，而现有预测模型往往只报告误差指标，缺少从预测分布到风险预警的统一评估流程。

## 2. 研究内容和论文结构

本文拟围绕工业设备异步多传感器的概率状态预测与风险评估开展研究，主要研究内容包括：构建工业异步多传感器数据协议与缺失模拟机制，明确训练、验证、测试划分和随机种子；构建 KAFNet-ProFITi 联合概率状态预测模型，在异步观测条件下输出未来多变量状态分布；构建基于预测分布样本的风险评分与鲁棒性评估方法，使预测结果能够服务于设备状态预警和风险判断。

拟定论文结构为六章。第 1 章为绪论，说明研究背景、研究现状、问题边界和论文组织。第 2 章介绍相关理论与技术基础，包括不规则时间序列建模、核激活网络、概率预测、归一化流和工业风险评估指标。第 3 章构建工业异步多传感器数据协议与缺失构造方法。第 4 章给出 KAFNet-ProFITi 联合概率状态预测方法。第 5 章围绕风险评估、缺失鲁棒性和统计验证展开实验分析。第 6 章总结全文工作并讨论后续改进方向。

## 3. 创新之处

本研究的创新点拟概括为三方面。其一，面向工业异步多传感器观测，构建兼顾时间间隔、观测掩码与工况信息的规整表示方法，用于缓解传感器异步采样和缺失观测对预测模型的影响。其二，将 KAFNet 的非线性表示能力与 ProFITi 的查询条件化概率预测框架结合，形成适用于多传感器未来状态联合分布建模的 KAFNet-ProFITi 方法。其三，围绕工业设备风险评估需求，设计从预测分布样本到风险分数、阈值预警和缺失鲁棒性评价的实验协议，使模型评估从单一预测误差扩展到概率质量与风险可用性。

## 4. 可行性分析

当前已经完成 KAFNet-ProFITi 融合原型、MetroPT-3 与 C-MAPSS 数据适配、统一结果保存目录和单 seed 冒烟实验。已有结果证明原型框架可运行，但尚不能作为最终论文对比结论。后续将补齐真实基线、消融实验、多 seed 统计、缺失鲁棒性和风险评估。

数据层面，MetroPT-3 与 C-MAPSS FD001 能够分别覆盖空气压缩机运行状态和航空发动机退化过程，适合支撑开题阶段的主要实验论证。TEP 可作为过程工业扩展验证，但在开题阶段不硬性承诺完整 faulty-run 主实验。方法层面，现有原型已经打通数据读取、掩码构造、模型训练和结果保存链路，后续主要工作集中在公平基线、消融变体、风险标签和统计汇总上。仓库层面，已经建立数据清单、上传边界和变更记录，可避免原始数据、权重和大型预测文件误传到 GitHub。

## 5. 研究方法与手段

本研究拟采用文献调研法、模型构建法、受控实验分析法和可复现仓库管理方法。文献调研用于梳理工业预测性维护、异步缺失时间序列、概率预测和风险评估的发展脉络；模型构建用于完成 KAFNet-ProFITi 主模型及其消融变体；受控实验用于比较主模型、真实基线和消融模型在统一数据划分、统一缺失 mask、train-only 归一化和固定随机种子条件下的表现；可复现仓库管理用于记录数据来源、配置、指标表和每次有意义的改动。

实验评价将同时关注点预测误差、概率预测质量、校准程度和风险识别能力。预测指标包括 MAE、RMSE、NLL、CRPS、PICP 和 ECE；风险指标根据数据集可获得标签确定，C-MAPSS 以 RUL 阈值构造风险标签，MetroPT-3 以故障报告窗口构造预警标签。多 seed 结果采用 `mean ± std` 汇总，核心比较在 2026、2027、2028 三个随机种子上完成。

## 6. 研究重点与难点

研究重点包括异步缺失协议、联合概率预测、风险评分和鲁棒性评估。异步缺失协议需要保证不同模型在相同观测条件下比较，避免由数据划分、缺失 mask 或归一化泄漏造成不公平结果。联合概率预测需要在多传感器输出之间保留相关结构，而不是仅对每个变量独立拟合边缘分布。风险评分需要把预测分布转化为可解释的运维指标，并与真实故障窗口或 RUL 阈值对应。

研究难点主要集中在四个方面。概率指标的公平比较要求所有模型在相同预测范围和相同观测条件下输出可比的分布信息；风险标签构造需要结合不同数据集的故障记录与退化定义，不能简单套用同一阈值；联合 flow 的训练稳定性会受到样本数量、缺失率和传感器维度影响，需要通过消融和训练日志判断问题来源；多 seed 统计需要控制运行时间和实验规模，在开题阶段优先完成最小真实矩阵。
